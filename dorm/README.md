# 생활관 홈페이지 (공개 화면 + 관리자)

대학교 생활관 홈페이지 형식(상단 GNB 메가메뉴 · 메인 비주얼 · 퀵메뉴 · 게시판 탭 · 오늘의 식단 · 일정 · 알림존 · 레이어 팝업 · 서브페이지 LNB)을 따른 **서버 없는 정적 홈페이지**입니다.

| 주소 | 용도 |
|---|---|
| `dorm/index.html` | 공개 홈페이지 (학생·방문자용) |
| `dorm/admin.html` | 관리자 페이지 (내용 수정·게시글 작성·식단 입력) |

## 유지 비용: 0원

- **호스팅**: GitHub Pages (무료). 서버·DB·관리형 CMS가 없어 월 이용료나 보안 패치 부담이 없습니다.
- **데이터 저장**: 모든 내용은 저장소의 `dorm/data/*.json` 파일입니다. 관리자 페이지가 GitHub API로 이 파일을 직접 커밋하고, Pages가 1~2분 안에 자동 재배포합니다.
- **수정 이력·백업**: 저장할 때마다 Git 커밋이 남으므로 언제든 이전 버전으로 되돌릴 수 있습니다.
- (선택) 학교 도메인(예: `dorm.OO.ac.kr`)을 쓰려면 Pages 설정의 Custom domain에 입력하고 DNS에 CNAME만 추가하면 됩니다. 추가 비용은 없습니다.

## 처음 설정 (1회)

1. **GitHub Pages 켜기** — 저장소 → Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)`.
   배포 후 주소: `https://student378.github.io/2025audit/dorm/`
2. **관리자 토큰 만들기** — GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
   - Repository access: *Only select repositories* → `2025audit`
   - Permissions → Repository permissions → **Contents: Read and write**
   - 만료일을 정해 두고(예: 1년), 만료되면 새로 발급해 다시 연결하면 됩니다.
3. `.../dorm/admin.html` 접속 → 토큰 붙여넣기 → **연결하기**.
   (소유자·저장소·브랜치·폴더는 github.io 주소에서 열면 자동으로 채워집니다.)

> 관리자 페이지 주소는 누구나 열 수 있지만, 저장소 쓰기 권한이 있는 토큰이 없으면 아무것도 바꿀 수 없습니다. 토큰은 GitHub 외 어디에도 전송되지 않고 해당 브라우저에만 보관됩니다. 공용 PC에서는 "토큰 기억하기"를 끄고, 사용 후 **연결 해제**를 누르세요.

## 관리자 페이지에서 할 수 있는 일

| 메뉴 | 내용 |
|---|---|
| 대시보드 | 게시물 수·이번 주 식단 등록 현황·노출 중 팝업, 최근 글 바로 수정 |
| 기본 정보 | 대학/사이트 이름, 로고, 대표 색상, 주소·연락처, 하단·상단 링크, 관련 사이트, 메인 게시판 탭 |
| 메뉴 · 페이지 | 대메뉴/하위메뉴 추가·삭제·순서, 종류(일반 페이지·게시판·식단표·일정·외부링크), 페이지 본문 편집기(표·이미지·지도 iframe) |
| 메인 비주얼 | 슬라이드 이미지·문구·버튼 링크 |
| 퀵메뉴 | 아이콘·이름·링크 |
| 팝업 · 알림존 | 기간 지정 레이어 팝업("오늘 하루 열지 않기" 지원), 알림존 배너 |
| 게시판 | 공지사항·입퇴사 공지·소식(갤러리형)·FAQ(아코디언형)·자료실, 상단 고정, 첨부파일 업로드, 게시판 추가 |
| 주간식단표 | 주 단위 입력, 엑셀 범위 복사→붙여넣기, 지난주 복사 |
| 생활관 일정 | 일정 등록 → 메인 목록과 월간 달력에 표시 |
| 연결 · 백업 | 전체 백업 내려받기 / 백업 파일로 복원 |

작업 흐름: **수정 → 미리보기 → 저장 · 배포** (저장 전까지는 홈페이지에 반영되지 않습니다).

### 토큰 없이 써 보기 (로컬 모드)

로그인 화면의 **로컬 모드로 둘러보기**를 누르면 토큰 없이 모든 편집·미리보기를 써 볼 수 있습니다. 저장하면 JSON 파일이 내려받아지며, 이 파일을 저장소의 `dorm/data/`에 올리면 반영됩니다.

## 파일 구조

```
dorm/
├── index.html          공개 화면
├── admin.html          관리자
├── assets/
│   ├── site.css / site.js     공개 화면 스타일·로직 (해시 라우팅: #/m/{메뉴ID})
│   ├── admin.css / admin.js   관리자 스타일·로직 (GitHub Contents API)
│   └── icons.js               퀵메뉴 아이콘 세트 (공용)
├── data/
│   ├── site.json       설정·메뉴·페이지 본문·슬라이드·퀵메뉴·팝업·배너·일정
│   ├── posts.json      게시판 목록과 게시물
│   └── meals.json      식단 (날짜별 조식/중식/석식)
└── uploads/            관리자에서 올린 이미지·첨부파일
```

## 로컬에서 확인

```bash
cd 2025audit
python3 -m http.server 8000
# http://localhost:8000/dorm/  ,  http://localhost:8000/dorm/admin.html
```
(`index.html`을 파일로 직접 열면 JSON을 불러올 수 없으니 반드시 웹서버로 여세요.)

## 참고·한계

- 기본 데이터의 학교명·주소·금액·식단은 모두 **예시**입니다. 관리자 페이지에서 실제 내용으로 바꿔 주세요.
- 저장소 루트의 `robots.txt`가 모든 검색엔진을 차단하고 있어 이 홈페이지도 검색에 노출되지 않습니다. 검색 노출이 필요하면 `robots.txt`에 `Allow: /2025audit/dorm/` 등을 조정하세요.
- 조회수·댓글·로그인 같은 서버 기능은 없습니다(유지비 0원을 위한 선택). 온라인 신청 등은 학교 포털이나 구글 폼 링크를 퀵메뉴·메뉴(외부 링크)로 연결하세요.
- GitHub Pages는 공개 저장소에서 무료입니다. 첨부 파일은 공개되므로 개인정보가 담긴 파일은 올리지 마세요.
