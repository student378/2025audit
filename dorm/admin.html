관리생활관 홈페이지 관리자

홈페이지 내용은 GitHub 저장소의 데이터 파일에 저장됩니다.
저장소에 쓰기 권한이 있는 GitHub 토큰으로 연결하세요.

토큰 발급 방법
  1. GitHub → Settings → Developer settings → Fine-grained tokens에서 Generate new token
  2. Repository access: Only select repositories → 이 저장소만 선택
  3. Permissions → Repository permissions → Contents: Read and write
  4. 만료 기간을 정하고 생성한 토큰(github_pat_…)을 위에 붙여넣기

토큰은 GitHub 외 어디에도 전송되지 않으며, 이 브라우저에만 보관됩니다.
